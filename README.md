# Life Sim — Living World v2

Static browser life simulation for GitHub Pages.

## New in v2
- Contextual category panels instead of one flat action list.
- School dashboard with subjects, scores, GPA, class rank, attendance, clubs, contests and exam countdowns.
- People have moods and specific memories.
- Phone/messages/social world panel.
- Places & actions panel for home, outside, wellbeing, work and business.
- Scheduled academic deadlines and contextual reminders.
- Random life events and world ticks.
- Event chains are designed to grow from NPCs, schedules and consequences.
- Age-up system and autosave/export/import.

## GitHub Pages
Put `index.html`, `style.css`, `game.js` and `.nojekyll` in the repository root. The included `.github/workflows/pages.yml` deploys with GitHub Actions.
