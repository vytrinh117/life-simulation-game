# Age & Action Rules

This file is the design source of truth for age-appropriate actions.

| Life stage | Independent actions | Caregiver-dependent / permission actions | Hidden / unavailable |
|---|---|---|---|
| Infant (0) | Sensory play / react | Feeding, bathing, sleep, toileting, outings | Phone, school, business, travel planning, cooking, romance, jobs |
| Toddler (1–2) | Play, practice emerging skills | Feeding/self-feeding practice, potty, bathing, dressing, outings | Phone, money management, business, travel planning, cooking, romance, jobs |
| Early childhood (3–5) | Play, kindergarten preference, emerging self-care | Kindergarten decision, playdates, family outings, hygiene/dressing help | Phone, business, independent travel, jobs, romance |
| Child (6–9) | School, age-appropriate study/play, choose stand ideas | Outside activities, trips, lemonade/baking stand, yard sale | Phone, independent travel, regular jobs, romance, investing |
| Preteen (10–12) | School, friends, simple self-care/cooking as skills allow | Outings/trips, small selling, household permissions | Phone, dating action, regular jobs, investing |
| Young teen (13–14) | School, friendships, age-appropriate romantic possibilities | Travel/outings and selling still under household permission | Personal phone, regular jobs, investing, independent travel |
| Older teen (15–17) | Phone only if owned, school, social apps with phone, more planning autonomy | Travel permission; work begins at 16; household rules still matter | Investing, fully independent travel |
| Adult (18+) | Independent travel, work, investing, phone/social, adult health/career systems | Context-dependent only | — |

Core rule: the UI should not show an adult action and then merely reject it after clicking. The visible action itself should change to the age-appropriate version.
